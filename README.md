# 📚 Електронний щоденник здобувача освіти (Palamar ERP)

Це повноцінна навчальна ERP-система, розроблена на базі Django, яка автоматизує процеси обліку успішності, відвідуваності та управління навчальним процесом.

## 🚀 Основні можливості

### 👥 Користувачі та ролі
- **Адміністратор:** Управління користувачами, підтвердження реєстрацій студентів, налаштування довідників.
- **Викладач:** Виставлення оцінок, масова відмітка відвідуваності, створення завдань та перевірка робіт.
- **Студент:** Перегляд розкладу, здача завдань, моніторинг власного рейтингу та відвідуваності.

### 📅 Навчальний процес
- **Розклад:** Гнучка система розкладу з перевіркою накладок для викладачів та аудиторій.
- **Відвідуваність:** Модуль швидкої масової відмітки групи на конкретну дату.
- **Оцінки:** Журнал успішності з фільтрацією за предметами, типом контролю та автоматичним розрахунком середнього бала.
- **Завдання:** Система завантаження робіт (.pdf, .docx, .zip) з контролем дедлайнів.

### 📊 Аналітика та Звіти
- **Інтерактивні графіки:** Візуалізація успішності за допомогою Chart.js.
- **PDF-експорт:** Генерація офіційних виписок оцінок (транскриптів) через WeasyPrint.
- **Рейтинг:** Автоматичний розрахунок середнього бала для студентів та цілих груп.

---

## 🛠 Технічний стек

- **Backend:** Python 3.12, Django 5.x
- **Frontend:** Bootstrap 5, Bootstrap Icons, Chart.js
- **Database:** SQLite (ізольована в Docker volume)
- **PDF Engine:** WeasyPrint (GTK+ інтеграція)
- **DevOps:** Docker, Docker Compose

## 💻 Швидкий запуск через Docker (Рекомендовано)

Проєкт повністю докеризований, що дозволяє запустити його однією командою без встановлення системних бібліотек.

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/your-username/palamar-diary.git
   cd palamar-diary
   ```

2. **Запустіть контейнери:**
   ```bash
   docker-compose up -d --build
   ```

3. **Заповніть базу даних тестовими даними (Seed):**
   ```bash
   docker exec -it diary_django python manage.py seed_data --clear
   ```

4. **Відкрийте сайт:**
   Перейдіть за адресою [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## ⚙️ Локальне встановлення (без Docker)

Якщо ви бажаєте запустити проєкт локально:

1. **Встановіть залежності:**
   ```bash
   pip install -r requirements.txt
   ```
   *Примітка: Для роботи WeasyPrint на Windows необхідно встановити бібліотеку GTK3.*

2. **Виконайте міграції:**
   ```bash
   python manage.py migrate
   ```

3. **Запустіть сервер:**
   ```bash
   python manage.py runserver
   ```
